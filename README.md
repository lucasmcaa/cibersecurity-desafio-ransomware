# cibersecurity-desafio-ransomware
Implementar um Ransomware para criptografar arquivos utilizando a linguagem Python.

*Aviso: Este repositório deve ser usado apenas para fins educacionais, de pesquisa defensiva e testes em ambientes isolados (máquinas virtuais ou sandboxes desconectadas da rede). A criação, distribuição ou uso de software que cause dano a terceiros, incluindo ransomware real, é ilegal e antiético. Todo trabalho aqui deve seguir leis, políticas institucionais e práticas de segurança responsáveis.*

# Estrutura do repositório
- encrypter.py — script de simulação que transforma arquivos de teste usando operações reversíveis e registradas.
- decrypter.py — script que reverte as transformações aplicadas por encrypter.py.
- teste.txt — arquivo de exemplo para testes.
- images/ — diretório contendo todas os prints da simulação.

# Passos executados na simulação
- criado a pasta com mkdir projeto-ransomware
- criado o arquivo encrypter.py
- criado o arquivo decrypter.py
- criado o arquivo alvo teste.txt
- executado o arquivo encrypter.py com python
- aberto o teste.txt encriptografado
- executado o arquivo decrypter.py com o python
- aberto o teste.txt descriptografado
